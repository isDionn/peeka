Peeka

A Dynamic-Island-style top strip for Windows, with a ghost that keeps you company.

Download for Windows View on GitHub

Free and open source (MIT). One portable exe for Windows 10 and 11, no installer. It is not code-signed yet, so SmartScreen may warn: choose More info, then Run anyway. The interface is in Turkish for now.

Your taskbar, but it pays attention.

Peeka replaces the Windows taskbar with a thin strip along the top of the screen. When something happens, a song starts, a download finishes, a timer runs out, Claude Code asks for permission, the island in the middle grows into a card. A second task waits in a small bubble beside it.

Everything the taskbar did, and a bit more.

Strip

A top bar that does the taskbar's job: running apps, tray, start and search, system status. Clicking it never steals focus. Hover an app for a live window preview.

Island

The central pill expands into cards for what is happening now: media, alerts, a timer, a finished download, a Claude Code session, plugin cards.

Side bubble

Short, quiet messages and a second task next to the island instead of full pop-ups.

Ghost mascot

A ghost hangs below the island and reacts to what the island is doing.

Quick settings

Wi-Fi, Bluetooth, volume and battery within reach, plus brief island events when volume, brightness or radios change.

Clipboard history

Text, images and file paths. Password-like items are recognised and shown blurred, and a vault keeps them encrypted with Windows DPAPI.

Media

The current track from Windows media sessions, with play, pause and skip.

Notifications

An optional mirror of Windows notifications, plus Peeka's own. One-time codes copy with one click.

Timer

A countdown that lives in the island.

Claude Code

One button in Settings adds Peeka's hooks to Claude Code. Sessions, tool use and permission requests then show up in the island. Another button removes exactly those entries.

Plugins

Any program can add island items, cards, search results and alerts over a local named pipe. You approve each plugin, scope by scope.

Setup wizard

Three steps on first launch: taskbar, optional notification mirror, Windows banners. Available again any time.

Nothing leaves your PC.

Peeka runs locally. Its own code makes no outbound network requests: no update check, no analytics, no telemetry. This page has none either.

Plugins may use their own internet connection. Peeka cannot control that, and the approval window says so.

  • Passwords stay blurred. Password rows in the clipboard stay blurred until you hover or focus them, and the real text is not in the page until then.
  • Lock and presentation modes. While locked, or while Windows is in presentation mode, the strip and bubble show generic labels instead of content, and nothing is sent to plugins.
  • One-time codes clean up after themselves. A code copied from a notification is cleared from the clipboard after 60 seconds, unless you copied something else since.
  • Mic and camera indicator. A dot shows which apps are using the microphone or camera, read from Windows' own consent store.
  • Local listeners only. A per-user named pipe for plugins, and an optional alert API on 127.0.0.1 that is off by default and needs a per-install key.
  • Your data stays on disk, in your profile. Settings, the clipboard vault and plugin tokens live in your local app data folder.

Add your own cards with a local plugin API.

Plugins talk to Peeka over JSON-RPC 2.0 on a user-only named pipe. They send data and Peeka draws it: no HTML, CSS or scripts from plugins, scoped permissions, and an approval window that Peeka draws itself. You can disconnect a plugin at any time.

Read the plugin API docs SDK examples (Python, Node)

The API contract is written in Turkish for now.
